# 🚜 OHT Tire Quality Analytics

### Turning Manufacturing Data into Meaningful Insights

**A Data Analytics Project for OHT Tyre Manufacturing Quality Improvement**

## 📌 1. Project Overview

This project focuses on analyzing OHT (Off-Highway Tyre) manufacturing quality data to identify defects, monitor production quality performance, investigate quality issues, and generate actionable business insights.

The objective is to transform manufacturing data into meaningful information that supports quality improvement and data-driven decision-making.

## 🎯 2. Project Objectives

| No. | Objective | Focus |
|---|---|---|
| 01 | Analyze Tyre Quality Performance | Quality monitoring |
| 02 | Identify Major Quality Defects | Defect analysis |
| 03 | Perform Root Cause Analysis | Problem investigation |
| 04 | Generate Actionable Business Insights | Quality improvement |
